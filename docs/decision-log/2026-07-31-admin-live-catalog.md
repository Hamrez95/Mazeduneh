# اتصال زنده کاتالوگ پنل مدیریت به API

## مسئله

پنل مدیریت صرفاً داده نمایشی داشت و ثبت محصول در آن به Backend و PostgreSQL متصل نبود. در نتیجه تیم فروش و انبار نمی‌توانستند جریان واقعی افزودن و مشاهده کالا را ارزیابی کنند.

## تصمیم

یک Vertical Slice کامل برای کاتالوگ ساخته شد که شامل Client مستقل Flutter، مدل‌های Product/Variant، صفحه Responsive محصولات، وضعیت‌های Loading/Empty/Error، Retry و فرم ثبت محصول است.

آدرس API با `MAZEDUNEH_API_BASE_URL` و `--dart-define` تنظیم می‌شود و هیچ Secret داخل اپ قرار نمی‌گیرد.

## معیار پذیرش

- دریافت محصولات منتشرشده از `GET /api/v1/products/`
- نمایش Variant و موجودی هر بسته
- ثبت محصول وزنی یا عددی با `POST /api/v1/products/`
- نمایش پیام فارسی Validation یا Conflict
- Retry در خطای شبکه
- تست parsing و خطای Conflict
- عدم فعال‌سازی پرداخت یا اطلاعات حساس

## میزگرد و نقد

- **مدیر محصول:** اتصال کاتالوگ ارزشمندترین مسیر بعد از ماندگاری PostgreSQL است.
- **مدیر فنی:** API Base URL باید محیطی باشد؛ این تصمیم اجرا شد.
- **Flutter:** Client از Widget جدا شد تا تست‌پذیر و قابل جایگزینی باشد.
- **Backend:** قرارداد فعلی Product/Variant بدون DTO اضافی مصرف شد.
- **UI/UX:** Loading، Error، Empty و Success همگی حالت طراحی‌شده دارند.
- **فروش:** فرم سریع فعلی برای ورود MVP مناسب است، اما افزودن چند Variant هم‌زمان باید در گام بعد بهتر شود.
- **انباردار:** موجودی روی Variant و به‌صورت تعداد بسته نمایش داده می‌شود.
- **حسابدار:** قیمت فعلاً ریال است؛ قیمت خرید و حاشیه سود هنوز وارد نشده‌اند.
- **متخصص خشکبار:** Grade، فرآوری، آلرژن و تاریخ بسته‌بندی در مدل Batch آینده افزوده شود.
- **QA:** خطاهای 409 و Retry باید تست شوند؛ تست Client اضافه شد.
- **گرافیست/برند:** فرم و کارت‌ها از سیستم رنگی سبز، کرم و پاستیلی مزه‌دونه استفاده می‌کنند.

## ریسک باقی‌مانده

- API آنلاین دائمی هنوز استقرار Production ندارد؛ Vercel فقط Frontendها را میزبانی می‌کند.
- فرم این برش یک Variant اولیه می‌سازد؛ ویرایش چند Variant و Upload تصویر در برش بعدی انجام می‌شود.
- احراز هویت مدیر پیش از عمومی‌شدن پنل الزامی است.

## اجرای محیط

```bash
flutter run -d chrome --dart-define=MAZEDUNEH_API_BASE_URL=http://localhost:5000
```
