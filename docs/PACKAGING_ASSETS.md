# Mazeduneh packaging asset map

All packaging artwork in this change is stored as transparent WebP under `apps/storefront/public/products`.

- `pistachio-pouch.webp`: routine pistachio stand-up pouch
- `almond-pouch.webp`: almond character pouch
- `walnut-character.webp`: walnut character pouch
- `mixed-nuts-character.webp`: mixed-nuts character pouch
- `cocoa-cookie-dragon.webp`: cocoa cookie carton with an original night-dragon character
- `one-kilo-box-packaging.webp`: one-kilogram folding box concept
- `cookie-mouth-packaging.webp`: cookie carton with die-cut mouth concept
- `gift-wrap-packaging.webp`: gift pouch/box with reusable belly band

The storefront maps products by slug/title to the closest packaging asset and uses the same assets in the responsive hero packaging rail. Product-card art is decorative only; food labeling, nutrition, legal text and final dielines must be supplied by the printer before production.
