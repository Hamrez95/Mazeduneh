# Brand direction — Mazeduneh

## Proposed identity

- Name: **مزه‌دونه**
- Latin spelling: **Mazeduneh**
- Working line: **خوش‌خوراکِ هر روز**
- Brand promise: everyday snacks with a little more care: selected nuts, sun-dried fruit, handmade fruit leather, lower-sugar cookies, and protein treats.

## Why this name

It sounds friendly in Persian, is easy to pronounce, and can stretch across nuts, dried fruit, homemade snacks, and gifts without limiting the shop to one product. A preliminary exact-name web search did not surface an obvious food retailer using it. `mazedoone.com` was reported available in the initial domain check on 2026-09-25. This is a working name, not a legal name clearance; check the Iranian trademark registry and `.ir` domain registrar before packaging or advertising.

## First design direction

- RTL-first, mobile-first storefront.
- Cedar green `#31584A` and deep cedar `#203E34`, with warm cream `#FAF7EF`, paper `#FFFDF8`, sage, and dried-apricot accents.
- Vazirmatn typography.
- Clear category discovery, best sellers, dietary notes, and gift bundles inspired by the supplied Nutty Delights reference; all text and artwork remain original.
- Admin is a separate Flutter web app with installable PWA manifest and dedicated icons.

## Prototype boundaries

The current storefront uses sample products, orders, and prices. Checkout is simulated; payment, fulfillment, stock changes, customer data, and privileged admin access still require backend integration and production security review.
